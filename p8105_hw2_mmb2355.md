## Problem 1

### read and clean data; character to logical variable

``` r
nyc_transit_df =
  read_csv(
    "NYC_Transit_Subway_Entrance_And_Exit_Data.csv",
    col_types = cols(Route8 = "c", Route9 = "c", Route10 = "c", Route11 = "c")) |> 
  janitor::clean_names() |> 
  select(
    line, station_name, station_latitude, station_longitude, 
    starts_with("route"), entry, exit_only, vending, entrance_type, 
    ada) |> 
  mutate(entry = ifelse(entry == "YES", TRUE, FALSE)
    )
```

In nyc_transit_df, the variables are station name, staion latitude,
station longitude, routes served, entry, exit, vending, entrance type,
and ADA compliance. The data was read and cleaned, and the entry
variable was changed from a character to logical variable. There are
1,868 rows and 20 columns. The data is not tidy yet because “route” and
“route number” are not variables after the prior adjustments.
